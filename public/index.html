🏛️ Arquitectura Single-Table Design con Turso + JSONB

Todos los módulos comparten exactamente una sola tabla SQL llamada records con 5 columnas. Cada módulo guarda sus datos dinámicos en binario nativo con jsonb(?) y los consulta con json(content) mediante la clase base ModuleRepository.

Tabla Única records (libSQL / Turso)
Columna Content BLOB NOT NULL (JSONB)
Aislamiento de Ramas 1 rama = 1 carpeta = 1 módulo
Pull Requests Hacia main con cero conflictos
